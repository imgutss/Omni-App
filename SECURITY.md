# Security policy

Do not include tokens, subscription URLs, private keys, unredacted logs or private backups in a public issue.

For a sensitive vulnerability use the repository's **Security → Report a vulnerability** private-reporting option when available. If a private reporting route is not available, open a minimal issue asking the maintainer for a private contact **without publishing exploit details or credentials**.

Include the affected version, impact, minimal reproduction and a safe redacted example. No response-time or remediation guarantee is implied.

Only download APKs from the official [Omni releases](https://github.com/imgutss/Omni-App/releases), verify SHA256SUMS and review release-specific validation notes. The project does not guarantee anonymity or the privacy of third-party VPN endpoints.
