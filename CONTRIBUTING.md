# Contributing to Omni

Thank you for helping improve Omni — imgutss.

- Open an issue with clear reproduction steps, expected behavior and device/build details. Redact secrets first.
- Read the applicable `AGENTS.md` guides. Keep presentation changes separate from engine changes.
- Preserve native VPN, import/export, protocol editing, persistence and permission behavior. Do not substitute fake status or demo metrics.
- Add tests for changed behavior. Screenshots show appearance, not working callbacks or real connectivity.
- Retain licenses, notices and attribution. Do not commit tokens, keystores, private profiles, local dumps or generated binaries.
- Use descriptive commits and focused pull requests. Document the exact checks run and those not run.

Build instructions: [docs/BUILDING.md](docs/BUILDING.md). Security reporting: [SECURITY.md](SECURITY.md).
