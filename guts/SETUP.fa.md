# راه‌اندازی GUTS قدم‌به‌قدم

کل کار سه تکه است و یک رمز که هر سه جا عیناً تکرار می‌شود. اگر هر جا گیر کردی، جدول خطاهای آخر همین فایل را ببین؛ تقریباً همه‌ی خطاها اسم و رسم دارند.

```text
📱 گوشی ──TLS با نام گوگل──► لبه‌ی گوگل ──► در (Apps Script روی اکانت گوگل تو)
        ──► خروجی (Exit Node) ──► اینترنت
```

| قدم | چی می‌سازی | کجا | چند دقیقه |
|---|---|---|---|
| ۱ | خروجی | GitHub Actions (یا VPS خودت) | ۳ |
| ۲ | در | ‏script.google.com با اکانت گوگلت | ۵ |
| ۳ | پروفایل | داخل اپ Omni | ۲ |

## قبل از شروع: یک رمز

یک رشته‌ی طولانی و تصادفی بساز (مثلاً ۴۰+ کاراکتر). این **کلید مشترک** است و در هر سه قدم دقیقاً همین می‌آید:

- قدم ۱: ورودی `key` ورک‌فلو (یا سکرت `GUTS_KEY` ریپو)
- قدم ۲: خط `AUTH_KEY` در ‏Code.gs
- قدم ۳: فیلد **Shared key** در اپ

این رمز + آدرس در را به کسی نده؛ هر کس هر دو را داشته باشد از سهمیه‌ی اکانت گوگل تو و از خروجی تو استفاده می‌کند.

## قدم ۱ — خروجی (Exit Node)

### راه رایگان: GitHub Actions

ورک‌فلوی «guts exit» در این ریپو هست (`.github/workflows/guts-exit.yml`). یا از روی همین ریپو اجرا کن، یا آن فایل را به ریپوی خودت کپی کن (در آن صورت نیازی نیست اینجا تغییری بدهی؛ ورک‌فلو کد را از برنچ `guts` می‌خواند).

1. (یک‌بار، اختیاری ولی راحت‌تر) رمز را سکرت کن تا هر بار تایپش نکنی:
   ‏Settings ← ‏Secrets and variables ← ‏Actions ← ‏New repository secret ←
   نام: `GUTS_KEY` ‏، مقدار: همان رمز.
2. تب **Actions** ← از لیست چپ **guts exit** ← دکمه‌ی **Run workflow**.
3. اگر سکرت نگذاشتی، رمز را در ورودی `key` بنویس. `minutes` یعنی خروجی چند دقیقه زنده بماند (پیش‌فرض ۳۳۰، سقف رانر ~۶ ساعت است).
4. اجرا که شروع شد واردش شو؛ در **Summary** همان اجرا بخشی به نام «guts exit URL» می‌آید:

```text
https://xxxx-xxxx.trycloudflare.com/g
```

این می‌شود `EXIT_URL` قدم بعد. تا وقتی آن اجرا زنده است خروجی کار می‌کند.

**تمدید سشن:** اجرا که تمام شد دوباره **Run workflow** بزن → آدرس تازه می‌گیری → در قدم ۲ فقط خط `EXIT_URL` را عوض کن و نسخه‌ی تازه دیپلوی کن (پایین‌تر). آدرس `/exec` و پروفایل گوشی دست نمی‌خورند.

### راه دائمی: VPS خودت

```bash
go build -o guts-exit ./cmd/exitnode
./guts-exit -addr :8080 -key "همان رمز"
```

پشت یک HTTPS عمومی‌اش بگذار (تونل نام‌دار cloudflared، یا nginx/caddy با دامنه‌ی خودت). `EXIT_URL` آن وقت ثابت است و قدم ۲ فقط یک‌بار انجام می‌شود.

## قدم ۲ — در (Apps Script)

فایل آماده همین‌جا است: [`apps_script/Code.gs`](apps_script/Code.gs) — کلش را کپی کن، فقط دو خطی که با «✏️ ویرایش کن» مشخص شده‌اند عوض می‌شوند.

1. برو به [script.google.com](https://script.google.com)، با اکانت گوگلت وارد شو، **New project**.
2. کد پیش‌فرض (`function myFunction() …`) را پاک کن و کل محتوای `Code.gs` را بچسبان.
3. دو خط اولِ کد:
   - `AUTH_KEY` ← همان رمز قدم ۱
   - `EXIT_URL` ← آدرس `/g` قدم ۱
4. ‏**Save** (Ctrl+S) و یک اسم برای پروژه بگذار.
5. ‏**Deploy** (بالا راست) ← **New deployment** ← چرخ‌دنده‌ی ⚙ کنار «Select type» ← **Web app**.
6. این دو را دقیقاً این‌طور بگذار:
   - **Execute as:** ‏Me
   - **Who has access:** ‏Anyone
7. ‏**Deploy**. گوگل اجازه می‌خواهد: **Authorize access** ← اکانتت ← اگر «unsafe» گفت **Advanced** ← **Go to …** ← **Allow**. (اسکریپت مال خودت است و فقط `UrlFetch` به خروجی خودت می‌زند.)
8. در پایان یک **Web app URL** می‌گیری که با `/exec` تمام می‌شود. همین را بردار؛ می‌رود قدم ۳.

**عوض کردن EXIT_URL در دفعات بعد:** خط را ویرایش و Save کن ← **Deploy ← Manage deployments ← مداد ✏️ ← Version: New version ← Deploy**. دیپلوی تازه از صفر نساز؛ آدرس `/exec` با همین روش ثابت می‌ماند.

**چند اکانت = سهمیه‌ی بیشتر:** همین قدم را با اکانت‌های گوگل دیگر تکرار کن (هر کدام یک `/exec` جدا، همان رمز و همان EXIT_URL) و همه را در اپ، هر خط یکی، بچسبان. سقف هر اکانت مصرف‌کننده حدود ۲۰٬۰۰۰ فراخوانی در روز است؛ کلاینت تماس‌ها را بین درها پخش می‌کند.

## قدم ۳ — اپ

اول هر VPN دیگری را قطع کن (اسکنر باید شبکه‌ی خودت را ببیند، نه داخل تونل دیگری را).

1. ‏Servers ← منوی ⋮ ← **GUTS**.
2. فیلدها:
   - **remarks**: هر اسمی.
   - **Doors (Apps Script web apps)**: آدرس(های) `/exec` قدم ۲، هر خط یکی.
   - **Shared key**: همان رمز.
   - **Google edge address**: بگذار `auto` بماند.
   - **Edge SNI**: بگذار `www.google.com` بماند.
3. روی **Scan this network for a working edge** بزن. اسکنر آدرس‌های لبه‌ی گوگل را از DNS همان خطی که رویش هستی می‌گیرد (ایرانسل، همراه اول یا وای‌فای، هر کدام pool خودشان را دارند) و هر آدرس را با همه‌ی نام‌های گوگل به‌صورت یک ماتریس تست می‌کند؛ سریع‌ترین زوجِ (آدرس، نام) که درخواست fronted را قبول کند داخل دو فیلد بالا نوشته می‌شود. روی خط کند تا ~۸۰ ثانیه طول می‌کشد.
4. تیک ذخیره (بالا راست)، پروفایل را انتخاب کن و وصل شو.

اگر نمی‌خواهی اسکن کنی: `auto` موقع وصل‌شدن هم خودش همان مسابقه را می‌دهد و اولین زوجِ جواب‌داده را انتخاب می‌کند؛ اسکن دستی آن زوج را داخل پروفایل قفل می‌کند تا اتصال‌های بعدی سریع‌تر باشند. خط یا اپراتورت عوض شد، دوباره اسکن بزن.

چه انتظاری داشته باشی: فقط **TCP** (وب، چت، تلگرام؛ تماس صوتی/تصویری و بازی آنلاینِ UDP نه)، هر تکه‌ی داده یک رفت‌وبرگشت از گوگل است پس برای ویدیوی سنگین ساخته نشده، و اگر خودِ گوگل هم کامل بسته شود هیچ راه ابری نیست.

## تست روی کامپیوتر (اختیاری، قبل از اپ)

```bash
gutsclient -door "https://script.google.com/macros/s/XXXX/exec" -key "همان رمز" \
           -google-ip auto -check
# door ok: guts/… via fronted script.google.com (edge …)

gutsclient -scan-matrix        # جدول کامل زوج‌های این خط: آدرس × نام، پینگ و وضعیت
```

## خطاها چه می‌گویند

| پیغام | یعنی چه | چاره |
|---|---|---|
| `unauthorized` | رمز یکی از سه جا با بقیه فرق دارد | هر سه جا را حرف‌به‌حرف یکی کن |
| `door: AUTH_KEY is still the placeholder` | خط رمز در Code.gs عوض نشده یا نسخه‌ی تازه دیپلوی نشده | ویرایش + Manage deployments ← New version |
| `door: EXIT_URL is still the placeholder` | همان، برای آدرس خروجی | آدرس ‎/g اجرای تازه را بگذار + New version |
| `exit answered non-JSON …` | آدرس خروجی مرده، یا به‌جای خروجی صفحه‌ی چالش برگشته | اجرای «guts exit» تازه بگیر و EXIT_URL را به‌روز کن |
| `No Google edge answered from this network` | این خط هیچ (آدرس، نام)ـی را رد نکرده، یا اسکن داخل تونل دیگری بوده | اول VPNهای دیگر را قطع کن؛ خط/وای‌فای دیگر را امتحان کن؛ دوباره اسکن بزن. به‌عنوان راه دستی، آدرس و نامی را که یک تستر دیگر روی همین خط جواب گرفته مستقیم در دو فیلد بنویس |
| وصل می‌شود ولی صفحه نمی‌آید | معمولاً خروجی در میانه‌ی سشن مرده یا سهمیه‌ی آن اکانت گوگل تمام شده | اجرای خروجی تازه؛ درِ بیشتر از اکانت‌های دیگر اضافه کن |
| چت کار می‌کند ولی تماس/بازی نه | طبیعی است: تونل فقط TCP است | — |
